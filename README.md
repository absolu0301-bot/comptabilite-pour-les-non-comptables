# Comptabilité pour les non-comptables — Version Premium

Cette version présente clairement Absolu comme le comptable et créateur de la marque « Le Comptable Absolu ».

Elle comprend :

- une présentation professionnelle de **Le Comptable Absolu** ;
- les formations et services comptables ;
- l'offre de systèmes et sites personnalisés ;
- des outils gratuits téléchargeables ;
- un portfolio présenté honnêtement comme prototypes ;
- un formulaire de devis avec message WhatsApp automatique ;
- un bouton WhatsApp fixe ;
- une mise en page adaptée aux téléphones.

## Lancer le site

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Remplacer l'ancienne version

Copiez `app.py`, `requirements.txt` et le dossier `assets` dans votre ancien dossier. Acceptez le remplacement des fichiers.
